# 🚀 Space Dodger

🚀 Space Dodger — یک بازی HTML5 مدرن و بدون وابستگی، ساخته‌شده با Canvas و جاوااسکریپت خالص.

🎮 **بازی آنلاین:** https://gamelabz.github.io/html5-game-space-dodger/

## 📸 تصویر بازی

![Space Dodger](assets/images/screenshot.png)

## 🎯 درباره بازی

سفینه‌ات را در میدان بی‌پایان سیارک‌ها هدایت کن و با لغزیدن از موانع تا جایی که می‌توانی زنده بمان.

## 🕹️ کنترل‌ها

- حرکت: کلیدهای جهت‌دار / WASD
- توقف موقت: P
- شروع دوباره: R

## ✨ ویژگی‌ها

- میدان مانع بی‌پایان
- کنترل تیز بدون اینرسی
- امتیاز بر پایه زمان بقا

## 🚀 اجرا در محیط محلی

نصبی لازم نیست. بازی را مستقیماً در مرورگر باز کن:

```bash
# روش اول: باز کردن مستقیم فایل
open index.html

# روش دوم: سرویس با یک سرور استاتیک کوچک
npx serve .
```

سپس به نشانی چاپ‌شده مراجعه کن (پیش‌فرض `http://localhost:3000`).

## 🛠️ تکنولوژی

- HTML5 `<canvas>`
- CSS3 (متغیرهای سفارشی، flexbox، گلس‌مورفیسم)
- جاوااسکریپت خالص (ES2020، بدون فریم‌ورک)
